# Asset starter pack

The generated illustration assets are original work made for Phàm Tu. The transparent PNG files are exported in sRGB-compatible PNG format and can be replaced independently as production art arrives.

| Path | Purpose | Size |
|---|---|---:|
| `backgrounds/background_main.png` | Main vertical game background | 1080×1920 |
| `characters/cultivator_01.png` | Seated cultivator sprite | 256×320 |
| `characters/cultivator_02.png` | Seated cultivator variant | 256×320 |
| `bosses/boss_world.png` | World boss sprite | 700×700 |

`logo.svg` and `throne.svg` are lightweight vector art. `vfx/` contains two tribulation effects, four Gift tiers, and the Heaven Dao palm; `icons/` contains XP, realm, heart, boss, and event icons. SVG source files are retained so the art remains easy to recolor and resize.

Quiz content is in `../data/quiz.json` (40 questions, UTF-8, four choices and one answer per entry).
